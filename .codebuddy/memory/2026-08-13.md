# 2026-08-13

## 归档审核弹窗修复
- 用户反馈：归档审核弹窗没显示审核意见输入框
- 原因分析：原来 `<n-form label-placement="left" label-width="80">` 配合 `label-width: 80px` 在 480px 宽度的 modal 里挤压了输入框
- 修复方案：改为 `label-placement="top"`，标签在上方，输入框独占整宽；按钮顺序调整：取消 → 通过 → 驳回

## 关键教训：naive-ui 组件必须显式 import
- 项目未开启 naive-ui autoImport，`<n-input>` 未 import 时渲染为空（标签正常，输入框塌陷）
- 排查"组件不渲染"时，先确认 `import { NXxx } from 'naive-ui'` 是否齐全

## n-modal preset="card" 表单布局经验
- 宽度有限时（≤ 500px）推荐 `label-placement="top"`，标签不会挤压输入框
- 复杂表单在窄 modal 里慎用 `label-placement="left"` + `label-width="80"`
- **重点：preset="card" 里 `<n-form>` + `<n-form-item>` 整块可能空白不渲染！改成 `<div>` + `<n-input>` 即可**
