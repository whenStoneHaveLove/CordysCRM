## BUG 修复：ExtAdOperationLogMapper.xml DTD 笔误导致启动失败
- 报错：`SAXParseException ... 无法读取外部 DTD 'mybatis-3-map.dtd'`，启动取消（adOperationLogService 注入失败 → operationLogAspect 失败）。
- 根因：XML 第2行 DOCTYPE 的 DTD 文件名写成 `mybatis-3-map.dtd`（笔误），正确应为 `mybatis-3-mapper.dtd`。项目所有其他 mapper XML 均用 `mybatis-3-mapper.dtd` 可正常启动（MyBatis 靠 PUBLIC id 在本地实体解析，不联网；错误文件名使解析器回退到 http 拉取，被 JDK `accessExternalDTD` 限制拦截）。
- 修复：改为与全项目一致的 `http://mybatis.org/dtd/mybatis-3-mapper.dtd`。
- 教训：新增 MyBatis mapper XML 时 DOCTYPE 必须复用项目现存写法，不要手敲 DTD 文件名。
