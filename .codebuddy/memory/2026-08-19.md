# 2026-08-19

## 改单创建按钮权限修复
- `frontend/.../advertising/change/index.vue` 的"新建"按钮漏了 `v-permission="['AD_ORDER_CHANGE:CREATE']"`，表格"提交"按钮（h() 渲染函数内）改用 `hasPermission('AD_ORDER_CHANGE:SUBMIT')` 判断（渲染函数不支持 v-permission 指令）。
- 根因：改单列表页整页漏了权限码控制，订单/客户/合同页都有。

## 订单草稿必填校验友好化（fix）
- `ad_order` 表多个 NOT NULL 无默认值字段（customer_id、rebate_mode、rebate_value、delivery_start/end_date、receipt_method、payment_method）前端原未校验，保存草稿时这些字段为空会直接触发后端 500。
- 改造 `create.vue` 的 `validate(action)`：草稿态校验所有"数据库 NOT NULL 无默认值"字段非空避免 500；提交态额外校验业务规则（totalAmount>0、框架合同必选、附件必传）。
- 错误提示用 `t('advertising.order.form.xxx')` + `required` 文案，友好。
- 注意 ESLint 规则 no-restricted-syntax：禁用 for...of 循环，改用 `.find()` 数组式写法。

## 工作台月度趋势金额始终为 0 的 bug
- `AdDashboardService.java` 取值 `row.get("amount")`，但 SQL 别名是 `totalAmount`，导致永远取到 null 返回 0。
- 修复：`row.get("totalAmount")`。订单数字段名正确，所以蓝色柱子正常。

## 管理员默认权限缺失补齐
- 初始化 SQL 里 `org_admin`/`ROLE_BOSS` 没授：上游代理 `AD_UPSTREAM_AGENT:*`、下游媒体 `AD_DOWNSTREAM_MEDIA:*`、操作日志 `OPERATION_LOG:READ`、改单提交 `AD_ORDER_CHANGE:SUBMIT`。
- 新增 Flyway V3.0.0_19__fix_missing_default_permissions.sql 幂等补齐。

## 广告操作日志默认权限补齐
